# RS-005 실제 모바일 검증 절차

TC-005-13은 **NOT RUN**이다. 이 작업 환경에는 실제 iPhone/Android 기기와 Safari/Chrome 연결이 없다. Chromium/WebKit의 데스크톱 자동화 및 모바일 뷰포트는 실기기 증거로 간주하지 않는다.

## 준비 및 실행

- 운영 DB 대신 격리된 테스트 SQLite와 테스트 서버를 준비한다. 외부 공개·방화벽 변경은 별도 승인 후 수행한다.
- 가능한 iPhone Safari와 Android Chrome 각각 기기 모델, OS 버전, 브라우저 버전, 실행 일시·시간대, 접속 환경을 기록한다.
- 다른 브라우저나 별도 클라이언트로 충돌 날짜를 선점할 수 있도록 준비한다. 합성 이름/메모만 사용하며 토큰·개인정보가 포함된 스크린샷/콘솔/화면 녹화를 증거에 저장하지 않는다.
- 세로·가로 회전에서 달력, 선택 목록, 이름/메모, 예약 버튼, 성공 정보와 취소 폼이 잘리지 않고 가로 스크롤 없이 표시되는지 확인한다.
- 터치로 비연속 날짜와 여러 월의 날짜를 선택하고 선택 유지·정렬·개별/전체 해제를 확인한다. 예약/차단/과거/기간 밖 날짜가 선택되지 않아야 한다.
- 날짜 두 개를 예약하고 성공 정보를 직접 보관한다. 복사 성공/권한 거부 시 수동 복사 안내를 확인한다. 화면 닫기 및 새로고침 뒤 토큰이 다시 표시되지 않아야 한다.
- 다른 클라이언트가 선택 날짜를 먼저 예약한 뒤 제출하여 409 안내·충돌 날짜 표시·관련 월 갱신·나머지 선택 보존을 확인한다.
- 잘못된 취소 정보, 확인 미체크, 정상 취소를 차례로 수행한다. 잘못된 요청은 점유를 유지하고 정상 취소만 달력이 갱신되어야 한다.
- 연결 끊김 및 응답 손실을 유도할 수 있는 승인된 테스트 환경에서 입력 유지·결과 불명 안내·자동 재제출 부재를 확인한다.
- 화면 확대, 포커스, 화면 읽기 도구의 상태 공지 및 레이블을 확인한다.
