기존 docs/DECISIONS.md는 변경하지 않았다. 추가 테스트 명세의 구체적인 검증 값은 계획상의 제안이다.

| 항목 | 제안/미확정 |
|---|---|
| 테스트 도구 | pytest/HTTPX 기존 유지, Playwright Python/pytest-cov 개발 전용 제안 |
| 날짜 테스트 | 고정 clock 2026-12-01 등 합성 날짜 |

| 성능 | 1/5/10 동시 조회 기준선, 실제 합격 기준 미확정 |
| API 계약 보완 | 400/422 매핑, 크기 제한 코드, 반복 취소 응답, PATCH 생략 의미, 관리자 월 조회 전체 날짜 반환, CSRF 토큰/만료, 로그 정렬 기준 |
