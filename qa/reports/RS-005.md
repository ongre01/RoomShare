## 결함 / 미해결 사항

- 수정 완료(제품): 오래 열린 탭이 KST 월 경계를 넘은 뒤 오늘 버튼을 누르면 이전 cached month를 표시하던 문제를 발견했다. 새 응답의 today 월을 따라가도록 수정하고 회귀를 추가했다.
- 수정 완료(제품): 달력 조회 도중 취소 요청이 실패하면 무시된 이전 응답 때문에 빈 달력과 로딩 안내가 남을 수 있었다. 중단 안내 및 새로고침 복구를 제공하고 느린 조회·취소 실패 회귀를 추가했다.
- 수정 완료(신규 테스트): 최초 TC-005-02는 취소 토큰의 password 입력을 로그인으로 오판해 1 FAIL/18 deselected였다. 실제 로그인 폼·관리자 링크·제외 콘텐츠를 검사하도록 수정했다.
- 수정 완료(개발 중 검증): 초기 E2E 3 FAIL/16 PASS는 미완성 CSS의 두 viewport 버튼 높이와, 의도적으로 비활성화된 빈 선택 예약 버튼을 클릭한 테스트 timeout이었다. CSS 완성 후 다시 검증하고, 빈 선택 제출 방어는 requestSubmit으로 확인했다. 이후 21 PASS, 추가 회귀 포함 23 PASS, 통합 대상 29 PASS. 기존 테스트 삭제/skip/assert 완화 없음.
- 수정 완료(신규 fixture): 최초 전체 회귀에서 session 범위 Playwright fixture의 실행 중인 asyncio loop가 E2E 이후에도 남아 기존 ASGI 단위 테스트의 asyncio.run 19개를 막았다. 제품 동작 실패가 아닌 테스트 수명 격리 결함이다. Playwright를 E2E 모듈 종료 시 닫도록 수정하고 기존 테스트를 그대로 유지해 함께 재검증하여 76 PASS를 확인했다. 같은 실행에 키보드 전용 Tab 이동 경로 보강도 포함했다. 수정 후 새 가상환경 전체 회귀도 482 PASS로 완료했다.
- 실기기 TC-005-13과 WebKit 실행 환경은 미검증이다. Safari/Android Chrome에서 예약·충돌·취소·회전·터치·복사·화면 읽기를 별도로 검증해야 한다. 장치 검증·관리자 접근 제어·프록시/TLS·OCI·복구 및 운영 정책 확인 전 전체 공개 릴리스는 NO-GO다.
