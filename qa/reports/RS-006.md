## 결함 / 미해결 사항

- RS-006 필수 로컬 게이트는 모두 충족했으며 미해결 차단 결함은 없다. 실제 외부 환경 항목은 아래와 같이 별도 미검증으로 유지한다.

- 검토 중 ASGI root_path 배포에서 raw path만으로 guard를 판별하면 실제 관리자 라우트와 불일치할 수 있음을 발견했다. Starlette와 같은 route path 및 raw path를 함께 검사하도록 보강하고 guard/응답·제한 회귀2개를 추가해 PASS했다.
- 실제 Nginx 인증서 검증/외부 header 위조/직접 backend 차단은 NOT RUN. RS-008/009에 명시 인계하며 운영 배포나 공개 릴리스 승인 증거가 아니다.
- 과거일/기간 상한/로그 페이지·보관/접근 범위는 운영 승인 전 임시 정책이다. 자동 이력 삭제는 추가하지 않았다.
- 실제 장치·OCI·백업 복원·전체 릴리스 검증과 정책 승인이 남아 공개 릴리스는 NO-GO다.
