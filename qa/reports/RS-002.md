- 수정 완료: Python sqlite3 timeout 초 단위 float가 정수 밀리초로 변환될 때 1001/1003ms가 1ms 줄어들어 정상 설정 거부. 검증된 정수를 PRAGMA busy_timeout에 명시 설정해 해결.
- 수정 완료: SQLite TEXT length/GLOB의 NUL 처리로 canonical UUID/64hex 뒤 NUL suffix 허용. instr(..., char(0))=0 및 typeof='text' CHECK를 추가해 NUL·BLOB 거부.

- Python 3.12.3 / SQLite 3.45.1 / Ubuntu 환경만 검증. 기존 HTTPX 경고, 운영 정책 확정, 실제 OCI/장치/프록시/복구 검증은 남아 있음. 전체 공개 릴리스는 NO-GO.
