- 상태: DONE
- 우선순위: P0

## 목표
로그인 없이 스마트폰에서 날짜 선택, 예약, 취소가 가능한 공개 UI 구현.

## 예상 변경 파일 (제안)
app/templates/index.html, app/templates/base.html, app/static/css/public.css, app/static/js/public.js, app/routers/public.py, tests/test_public_page.py, tests/manual/public-ui.md

## 구현 범위 및 세부 작업
1. `/` 페이지에 월 이동(이전/다음/오늘), 요일 7열 달력, 상태 범례, 선택 목록/개수, 이름/선택 메모, 예약 버튼, 결과 및 취소 폼 구현. 사진/금액/계정/관리자 링크 없음.
2. 달력 응답의 today/min_date/max_date를 사용하고 브라우저 UTC 변환으로 날짜를 하루 이동시키지 않는다. 날짜 문자열을 키로 Set 등에서 선택 유지, 정렬 표시, 개별 해제 및 전체 해제. 예약/차단/과거/기간 밖 날짜는 선택 불가. 색 외 텍스트/기호 및 접근성 이름 제공.
3. 월 이동 중 느린 이전 응답이 최신 화면을 덮지 않도록 처리. 선택된 다른 월의 날짜도 제출한다. 충돌 409 시 서버가 반환한 충돌 날짜를 표시하고 관련 월의 상태를 다시 확인, 가능한 선택은 보존한다. 이미 제출한 요청을 자동 재전송하지 않는다.
4. 입력 검증, 로딩/버튼 비활성화/중복 클릭 방지, 네트워크 오류/429/503/성공/충돌 표시. 이름/메모는 안전한 textContent 또는 템플릿 escape 사용. HTML 삽입 금지.
5. 성공 후 예약 ID/취소 토큰을 한 번만 표시하고 사용자가 직접 보관할 수 있는 복사 기능 제공. 토큰을 localStorage/sessionStorage, URL, 로그에 저장하지 않는다. 취소 폼은 ID+토큰 입력과 확인, 결과 및 달력 갱신을 제공한다.
6. 360px 모바일 우선, 키보드/터치 조작, 레이블/포커스/상태 공지 지원. 프레임워크/외부 CDN 필수 의존성 금지.

## 필수 테스트 시나리오
- 360px/390px/데스크톱 뷰포트 가로 overflow 여부, 버튼 터치/키보드 조작.
- 이전/다음 월 이동, 연도 경계, 비연속/복수 월 선택 유지 및 해제.
- 금지 날짜 선택 차단, 기간 밖 AVAILABLE 상태도 선택 불가.
- 정상 예약, 중복 클릭, 충돌 후 갱신, API 429/503/네트워크 오류, 취소 성공/실패.
- 느린 월 조회 응답 역전, HTML 입력 안전 표시, 토큰 저장/URL/캐시 부재.
- Safari/Chrome 실제 확인 여부 명시. 실제 브라우저 없으면 NOT RUN 기록.

## 구현 심화 지침 (v2, 제안)
1. 상태 모델을 월/선택 Set/입력/요청 중/오류/성공으로 분리한다. 날짜 키는 문자열 그대로 사용하며 today/min_date/max_date는 서버를 신뢰한다. 화면에서 금지 날짜를 막아도 서버 재검증을 생략하지 않는다.
2. 월 요청은 증가하는 요청 ID 또는 AbortController로 최신 응답만 반영한다. 다른 월의 선택을 유지하되 새로 금지된 날짜는 사용자에게 알리고 정리한다. 응답 손실과 명시적 409를 구분한다.
3. 성공 상태에만 토큰을 표시하며 복사 실패 시 수동 복사 안내를 제공한다. 새로고침 후 복구되지 않는다는 안내, 취소에 ID와 토큰 모두 필요하다는 설명을 넣는다. 콘솔/URL/storage에 기록 금지.
4. 실제 브라우저 E2E에서 API를 통째로 mock한 테스트와 실제 서버 연동 테스트를 구분한다. 오류/응답 역전은 intercept로 재현 가능하지만 정상 예약·취소·충돌은 실제 파일 DB와 서버로 검증한다.
