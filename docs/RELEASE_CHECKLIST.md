# MVP 공개 판정 — RS-009

**NO-GO.** [OCI VM에서의 격리 검증](../qa/reports/RS-008.md#oci-재검증)은 실행했지만 외부에서 접근하는 배포 서비스는 검증하지 않았다. [릴리스 후보 검증 보고서](../qa/reports/RS-009.md#oci-재검증)를 함께 확인한다. 아래 항목을 pytest 성공으로 대신하거나, 체크리스트만으로 서비스를 공개하지 않는다.

| 남은 확인 | 누가 / 어디서 | 필요한 증거 |
|---|---|---|
| 관리자 브라우저 회귀 | QA / 동일 후보·전용 환경 | OCI 전체 회귀 두 번 모두 TC-009-02 대기 시간 초과(두 번째는 관리자 테스트 3개 실패). 분리 실행 3개 통과로 면제하지 않는다. 원인 구분과 전체 회귀 통과 필요. |
| 배포 시스템 서비스 | 운영자 / 전용 Ubuntu, 합성 DB | TC-008-10/14는 격리 사용자 unit에서 재시작·timer 발화·실패 기록·복원 확인. TC-008-03의 실제 `roomshare` UID/GID·소켓·쓰기 경계와 배포된 시스템 unit/timer의 동작은 별도 확인. |
| 외부 접근 경계 | 운영자 / 서버 밖의 승인된 클라이언트 | TC-008-08 및 TC-009-05: 사용자·관리자 HTTPS, 인증된 관리자만 접근, 외부 백엔드 8000 거부. 공개 IPv6가 있으면 함께 확인. |
| 모바일 실제 장치 | QA / iOS Safari, Android Chrome | TC-005-13, TC-007-13, TC-009-08: [사용자](../tests/manual/public-ui.md)·[관리자](../tests/manual/admin-ui.md) 흐름과 기기·OS·브라우저별 결과. |
| 실제 OCI 배포 | 운영자 / 승인된 OCI 스테이징 | TC-008-16의 VM 합성 부하 기준선은 측정 완료(운영 SLO 미확정). TC-008-15·TC-009-10의 실제 도메인 DNS/TLS/mTLS, 보안 목록·NSG·OS 방화벽, 배포 서비스 재시작·복원 미검증. [배포 실행서 §5](DEPLOYMENT.md#5-승인-환경에서-남기는-증거-로컬과-oci-별도) 참조. |
| 정책·장애 시 복귀·공개 승인 | 운영자 | [미확정 정책](DECISIONS.md), 공개 범위와 관리자 인증서 관리, 백업 보존·별도 보관·RPO/RTO, 이전 릴리스와 호환되는 DB 및 복귀 연습, 성능 기준과 비용을 검토하고 결정을 기록. |

같은 후보 커밋에 대해 환경·시간·명령·종료 코드와 비밀 없는 결과를 남긴다. 실행 코드·설정·의존성이 바뀌면 해당 케이스와 전체 회귀를 다시 검증한다. 필수 실패 또는 미검증이 남으면 계속 NO-GO. 최종 공개는 별도 운영자 승인 사항이며 이 티켓에서 배포·태그·push·merge하지 않는다.
