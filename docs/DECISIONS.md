# 정책 및 미확정 사항
| 항목 | 초기 구현 기본값 (제안) | 상태 |
|---|---|---|
| 날짜 경계 | 한국시간 00:00~다음날 00:00 | 확인 필요 |
| 예약 가능 기간 | 오늘 포함 90일, 설정 가능 | 확인 필요 |
| 최대 예약 | 예약 가능 기간 내 별도 제한 없음 | 확인 필요 |
| 비연속 선택 | 지원, 월 이동 시 선택 유지 | 확인 필요 |
| 예약 확정 | 자동, 관리자 승인 없음 | 확인 필요 |
| 예약자 이름 노출 | 공개 달력은 상태만, 관리자만 이름/메모 조회 | 확인 필요 |
| 취소 | 취소 토큰으로 예약 전체 취소; 모든 날짜가 오늘 이후일 때만 사용자 취소 가능 | 확인 필요 |
| 관리자 | 별도 호스트 + mTLS 권장; 사설망 대안 | 확인 필요 |
| 사용자 접근 | 로그인 없는 공유 URL; 공개 범위 및 남용 방어 결정 필요 | 확인 필요 |
| 이력 보관 | 90일 임시값, 운영자 확인 후 확정 | 확인 필요 |
| OCI | Ubuntu 단일 VM, RAM 1GB 목표; 실제 인스턴스 미확인 | 확인 필요 |
| 도메인 | room.example.com / admin-room.example.com (예시) | 확인 필요 |

URL만 숨기는 방식은 접근 제어가 아니다. 사용자 예약 토큰 분실 시 관리자에게 요청한다. 예약 가능 기간과 최대 선택 개수는 서버에서 제한한다. 무료/유료 이용 여부 및 실제 주거 공유 운영 요건은 배포 전 운영자가 확인한다. 정책 변경은 문서·테스트·구현에 함께 반영한다.
